# AI4Uni Safe Phishing Demo

This is an offline-only awareness demo for a training session on copyright, licences, and device protection.

## How to use

1. Unzip the package.
2. Open `index.html` in a browser.
3. Show the fake login screen to the audience.
4. Ask: “Would you trust this after receiving a Microsoft 365 verification email?”
5. Click `Sign in`.
6. Discuss the red flags.

## Safety design

- No network calls.
- No credential collection.
- Read-only fields.
- No form submission.
- Immediate educational reveal after click.

## Presenter note

Do not ask participants to enter real passwords. This demo is for awareness only.
